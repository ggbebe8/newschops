# 순위 규칙 v1.1

score = .30 spread + .30 prominence + .25 impact + .15 recency. 결측 요소는 가중치 합으로 재정규화한다. spread = 100 * min(k, 10) / 10. k는 확인된 독립 origin 수(`known:`)가 있는 경우 이를 우선 반영하며, origin 취재 증거가 없는 초기 단계(`unknown:`)에서는 이슈를 보도한 고유 언론사(매체) 수(2곳 이상일 때 k=매체 수)를 확산도로 반영한다. 단일 매체 단신은 k=0이다. 이를 통해 주간·최근 7일 종합에서 여러 주요 매체가 일제히 다룬 중요 사건이 단발성 당일 최신 단신보다 우선 정렬되도록 보장한다.

recency = 100 * 2 ** (-h/H). 현재/1시간 H=12, 오늘/일간 H=24, 주간/최근7일 H=168. 영향은 근거가 없으므로 NULL이다. 배치는 동아일보 공개 목차 A1과 실제 기사ID가 연결될 때만 1면 기타85를 관측한다. 나머지는 NULL이다. 점수, 결측, 근거 충실도(배치 미관측 시 .45), 신뢰도를 표시한다. 동점은 독립 출처 수, 근거 충실도, 사건 시각, ID. 제목 수정/반복 기사로 사건 시각을 갱신하지 않는다.

현재 최근24시간, 최근1시간 60분, 오늘 KST 자정부터, 주간 KST 월요일부터, 최근7일 168시간. 일간 확정은 전날 KST 구간이며 00:10 이후, 주간 확정은 지난 월~일이며 월요일00:20 이후 처음 worker tick에 저장된다. 정시 슬롯 snapshot은 UNIQUE(period,slot)이며 20~25초 폴링으로 실행되어 정각에서 수십 초 지연될 수 있다.

기간 필터는 기사의 실제 발생/발행 시각(`coalesce(published, discovered)`) 기준으로 `[period_start, period_end)` 구간을 적용하며, 순위 평가 시각 `at` 이전에 수집된 자료(`collected <= at`, `discovered <= at`)를 대상으로 한다. 이를 통해 서비스 초기 기동 및 일간·주간 확정 구간에서도 과거 수집 기사가 정상 반영된다. 하루/주간을 시간순위 합산하지 않는다. 분야 최대4 후 후보 부족이면 완화 이유를 남긴다. 후보가 부족하면 10개를 채우지 않는다. 개인 관심은 별도 feed이며 종합에 영향을 주지 않는다.

제한: 중요 전개가 별도로 탐지되지 않아 최초 사건 시각으로 계산한다. 확정 일간/주간 정정 버전, 가중치 관리자 변경, 대형 사건 모드, 근거 충실도 보조 정렬 UI는 미구현이다. 현 버전에서는 규칙 변경 시 코드와 문서를 갱신해야 한다.

관리자 잠정 순위 정정 요청은 jobs에 이유와 actor를 기록한다. worker가 current/hour/today/week/7days의 새 snapshot 버전을 만들고 이전 결과는 그대로 남긴다. 정정 요청 쿨다운60초. 발행 시각으로 복구할 수 없는 이슈 시각은 time_estimated로 표시하고, 발행 시각이 NULL인 기사는 순위에서 제외한다. 수정 시각은 발행과 별도 저장하며 단순 수정으로 사건 전개시각을 갱신하지 않는다.
