# 결정 기록

- 2026-10-25: 명세의 FastAPI/SQLAlchemy/Alembic/PostgreSQL + React/TS/Vite, worker 구조 채택. Redis/Celery 없음.
- 본문 처리 권한을 확인할 수 없으므로 제목/원문 링크만 수집한다. 요약·매체별 논조·공통 사실을 제목에서 만들어내지 않는다. AI 환경변수는 예약이며 현재 외부 전송은 없다. 이는 완성된 AI 기능이 아니며 후속 작업이다.
- 독립 origin이 불확실하면 확산도에 더하지 않는다. 현 RSS 연결만으로 주요 배치/영향을 판단하지 않는다.
- 조건 불명·접근 실패 매체는 상태와 연결 결과를 그대로 노출한다. 검색 피드나 유료 소스로 임의 우회하지 않는다.
- 관리 계정 비밀번호는 처음 생성할 때만 사용. 재시작 시 덮어쓰지 않는다. 로컬 .env는 무작위 생성하며 Git에서 제외.
- 모델 변경/다중 에이전트 위임 없음. Git author는 사용자 설정을 요구하고 임의 생성하지 않는다.

- 2026-10-25: 원래 후보 3곳의 404/빈 응답 확인 후 서울신문·세계일보·SBS로 교체. 총 기본 풀10곳 유지. 경제지 별도 smoke403과 worker200을 함께 기록.
- 2026-10-25: 동아일보 공식 /news가 실제 공개 지면 목차임을 확인하여 목차만 수집. 회원 전용 지면 이미지와 유료 PDF에는 접근하지 않는다.
- 2026-10-25: 한글 글꼴이 없는 브라우저에서도 표시되도록 Noto Sans KR을 정적 번들에 포함. OFL 라이선스는 docs/licenses에 보존.
